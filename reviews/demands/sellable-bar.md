# Sellable bar

What “done enough to sell as a Hidden Door municipal audit sample” means — derived from the 2026-09-17 adversarial pass and standing scar/stitch/self-check rules.

1. KS-001 addressed (disclosure or selection story).
2. Byte-level captures + hashes for core PDFs/pages.
3. Genre honest (“audit” only if captures + rendition exist).
4. One public scorecard rendition (published / petition-only / not-found).
5. SOW stub: scope, non-goals, no-TPRA-filing default, acceptance criteria.
6. `privacy_class` matches reality.
7. Secondary COG codes pruned or cited.
8. Cold self-check ([CHECK-YOUR-OWN-WORK](../adversarial/CHECK-YOUR-OWN-WORK.md) A–G) run by someone who did not author the case — pass recorded.

**Until then:** methodology sample, not invoice hero piece.
